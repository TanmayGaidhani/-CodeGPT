## 📁 **3. Projects & Memory System**

### What are Projects?
Projects are folders where you can:
- Save conversations
- Organize by topic
- Continue later
- Keep notes and research

### How to Use Projects:

#### Create a Project:
1. Open tools panel (🛠️)
2. Scroll to "My Projects"
3. Click "+ New Project"
4. Enter project name
5. Project created!

#### Load a Project:
1. Open tools panel
2. Click on any project
3. Previous chats load automatically
4. Continue where you left off

#### Delete a Project:
1. Hover over project
2. Click × button
3. Confirm deletion

### Project Features:
- **Auto-save:** Chats save automatically
- **Multiple projects:** Create unlimited projects
- **Icons:** Random emoji icons for easy identification
- **Chat count:** See how many chats in each project
- **Timestamps:** Track when created/updated
